# Bundled typefaces

Both families are licensed under the SIL Open Font License, Version 1.1, which
permits bundling in an application, including a commercial one, provided the
licence travels with the files.

| Family | Designer | Source | Licence |
|---|---|---|---|
| Literata (400, 500, 600) | TypeTogether for Google | fonts.google.com/specimen/Literata | OFL-1.1 |
| Hanken Grotesk (400, 500, 600, 700) | Alfredo Marco Pradil | fonts.google.com/specimen/Hanken+Grotesk | OFL-1.1 |

Full licence text: https://openfontlicense.org (OFL-1.1). The upstream licence
file for each family ships in its Google Fonts repository directory.

These are static instances exported from each family's variable font, one file
per weight, so that no variable-font axis handling is needed at runtime.
